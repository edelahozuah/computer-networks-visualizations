Anatomy of a name: from labels to the tree

A name is written from the specific to the general; the tree is walked from the root downwards. Every suffix of the name is a domain, and every domain is a node of the tree.

Name rules
    Rules: RFC 1035 (63 characters per label; 255 octets in total in the message, which is 253 written characters), RFC 1123 (letters, digits and hyphen in host names) and RFC 5890 (internationalized names, encoded in punycode).
