DNS queries: you decide who is recursive

The host asks for gaia.cs.umass.edu, with every cache empty. As Kurose & Ross point out, in theory any DNS query can be iterative or recursive: choose how each server handles the queries it receives and see what changes.

An extension of Figs. 2.19 and 2.20 in Kurose & Ross. Simplified model: a “recursive” server resolves whatever it is asked on its own (RD = 1 and RA = 1); an “iterative” one replies only with what it knows, usually a referral. You can also change a server’s mode by clicking the label next to it in the diagram. The configuration is stored in the page address, so you can share it.
