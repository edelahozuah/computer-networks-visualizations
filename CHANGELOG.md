# Changelog

All notable changes to this repository are listed here. Each release gets its
own DOI on Zenodo; the concept DOI in the README always points to the latest.

## [Unreleased]

### Added
- Browser cache: cache or server? (`http-cache`, session 2.3): decision tree, sequence
  diagram and cache table for a page visited several times, with exercises. Source in
  `src/http-cache` (engine tested by `test_motor.js`).

### Removed
- Speaker notes and presenter window of the DNS step by step source
  (`src/dns-step-by-step`); the build now matches the published files.

## [0.1.0] - 2026-10-10

DOI: [10.5281/zenodo.23285665](https://doi.org/10.5281/zenodo.23285665)

### Added
- Repository created from the visualizations published on
  [edelahozuah.github.io](https://edelahozuah.github.io/docencia/ar1/)
  (topics 1 and 2 of Network Architecture I, 2026/27):
  14 visualizations, each in Spanish and English.
- `catalog.yml` with titles, descriptions, summaries, concepts and formulas.
- Modular source and build scripts of the delay diagram, persistent HTTP and
  DNS step by step, and the design template of the delay lab.
- `index.html` catalogue page, generated by `scripts/build_index.py`.
- `scripts/check.py`: validates the catalogue and the HTML files.
