# Changelog

All notable changes to this repository are listed here. Each release gets its
own DOI on Zenodo; the concept DOI in the README always points to the latest.

## [Unreleased]

### Added
- Browser cache: cache or server? (`http-cache`, session 2.3): decision tree, sequence
  diagram and cache table for a page visited several times, with exercises. Source in
  `src/http-cache` (engine tested by `test_motor.js`).
- Cookies: state on top of HTTP (`http-cookies`, session 2.3): decision tree, sequence
  diagram with Cookie/Set-Cookie/Referer, cookie store and what each server knows, for several
  sites visited several times (expiry, session cookies, third-party tracking), with exercises.
  Source in `src/http-cookies` (engine tested by `test_motor.js`).
- Topic 3, transport layer (`03-transport-layer`).
- Which socket? UDP and TCP demultiplexing (`transport-demultiplexing`, session 3.1): socket table
  of a server receiving segments from several clients, UDP by (IP_D, PD) and TCP by the 4-tuple
  with welcome and connection sockets, replies with swapped ports, ephemeral ports, deck scenarios,
  prediction mode and exercises. Source in `src/transport-demultiplexing` (engine tested by
  `test_motor.js`).
- UDP checksum step by step (`udp-checksum`, session 3.1): one's complement sum of 16-bit words
  column by column with the carry wrapping around, both receiver checks, and bit errors in the channel
  (single-bit errors detected, compensating pairs not), with exercises. Source in `src/udp-checksum`
  (engine tested by `test_motor.js`).
- The UDP datagram and its pseudo-header (`udp-datagram`, session 3.1): header fields, Length and
  maximum sizes (65 527 B, 65 507 B over IPv4), the 12-byte pseudo-header built from the IPv4 header,
  and the IP → protocol → port cascade, with exercises. Source in `src/udp-datagram`.
- Reliable data transfer: stop-and-wait, GBN and SR (`reliable-data-transfer`, session 3.2):
  space-time diagram over a channel that loses, corrupts or delays packets (click on any packet or ACK),
  sender and receiver windows with sequence numbers modulo 2^k, timers, the book's scenarios (Fig. 3.16,
  3.22, 3.26, 3.27), windows that are too large, a sender utilization calculator, prediction mode and
  exercises. Source in `src/reliable-data-transfer` (engine tested by `test_motor.js`).

### Removed
- Speaker notes and presenter window of the DNS step by step source
  (`src/dns-step-by-step`); the build now matches the published files.

## [0.1.0] - 2026-10-10

DOI: [10.5281/zenodo.23285665](https://doi.org/10.5281/zenodo.23285665)

### Added
- Repository created from the visualizations published on
  [edelahozuah.github.io](https://edelahozuah.github.io/docencia/ar1/)
  (topics 1 and 2 of Network Architecture I, 2026/27):
  14 visualizations, each in Spanish and English.
- `catalog.yml` with titles, descriptions, summaries, concepts and formulas.
- Modular source and build scripts of the delay diagram, persistent HTTP and
  DNS step by step, and the design template of the delay lab.
- `index.html` catalogue page, generated by `scripts/build_index.py`.
- `scripts/check.py`: validates the catalogue and the HTML files.
